# Nozzle cap — print-ready package
- `nozzle_cap.stl` full part. `nozzle_cap_test_slice.stl` lowest 15 mm (rim + snap ribs) for a quick fit check.
- Generated by `nozzle_cap.py` (edit parameters at top, re-run; `TEST_SLICE_H=15 python3 nozzle_cap.py` makes the fit-test slice). Dimensions are estimates from photos.

## Bambu Studio settings (P1S)
- Orientation: as exported (rim flat on bed, tabbed end up). No supports.
- Filament: PLA for test fit; PETG for final if outdoors/wet.
- Layer 0.16 mm, 4 walls, 15% gyroid infill (part is mostly wall), 5 top/bottom layers.
- Small holes (<2.5 mm) print slightly tight: drill/ream or enlarge in script (HOLES list).
- Snap ribs/post: if they don't clear, change RIB_PROJ / CLR in the script.
